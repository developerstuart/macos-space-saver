# Screenshots

Add screenshots of the application here to help users understand how it works.

## Suggested Screenshots

1. **Menu Bar Icon**: Show the app icon in the macOS menu bar
2. **Menu Options**: Show the dropdown menu with all options
3. **Accessibility Prompt**: Show the accessibility permission dialog
4. **Save Notification**: Show the notification after saving a layout
5. **Restore Notification**: Show the notification after restoring a layout
6. **Config File**: Show the JSON configuration file open in a text editor
7. **Multi-Monitor Setup**: Show the app managing windows across multiple monitors
8. **Before/After**: Show desktop before and after restoration

## How to Add Screenshots

1. Take screenshots on macOS using `Cmd+Shift+4`
2. Save them to this directory with descriptive names (e.g., `menu-bar-icon.png`)
3. Update the main README.md to reference the screenshots

## Screenshot Guidelines

- Use PNG format for best quality
- Capture at regular resolution (not Retina 2x) for smaller file sizes
- Consider user privacy (don't include personal information)
- Show realistic use cases
- Include both light and dark mode if significantly different
